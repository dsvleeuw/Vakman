# docs/bedrijfsinformatie — Klusbaas Bedrijfsinformatie

Officiële bedrijfsgegevens, branding, juridische documenten en contactinformatie voor Klusbaas.

## Inhoud (gepland)

| Bestand | Beschrijving |
|---------|--------------|
| `bedrijfsgegevens.md` | KVK nummer, BTW-id, adres, bankrekening, contactpersoonnen |
| `branding.md` | Logo gebruik, kleurpaletten, typografie, tone of voice, do's & don'ts |
| `algemene-voorwaarden.md` | Algemene leveringsvoorwaarden (platform abonnementen) |
| `privacyverklaring.md` | GDPR privacy policy (Nederlands) |
| `cookiebeleid.md` | Cookie verklaring & beheer |
| `disclaimer.md` | Disclaimer voor demo sites & marketing materiaal |
| `contact.md` | Contactkanalen: support, sales, partnerships, pers |

## Gebruik

- Deze documenten zijn **referentie** voor het team en externe partijen
- Juridische teksten worden beheerd door juridisch adviseur
- Branding wordt beheerd door marketing/design
- Wijzigingen doorvoeren via PR met review

## Gerelateerd

- `public/brand/` — Visuele brand assets (logos, icons)
- `src/data/platform.ts` — Platform configuratie in code (naam, tagline, features)
- `src/utils/contact.ts` — Contact helpers (WhatsApp, tel, email builders)
