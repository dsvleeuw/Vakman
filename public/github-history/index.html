Wat betekent dit allemaal?

Commit (de codes zoals 3c8ed2e)
Een unieke code die elke "save" identificeert. De eerste 7 karakters zijn meestal genoeg.
Merge
Twee takken (branches) samenvoegen. Meestal na een pull request die goedgekeurd is.
Pull Request (PR)
Een voorstel om wijzigingen toe te voegen. Anderen kunnen dit reviewen voordat het samengevoegd wordt.
Branch / Tak
Een aparte werkomgeving. Je werkt op een tak, en als het klaar is, voeg je het samen met de hoofdtak (main).
Conventional Commits (feat:, fix:, docs:, chore:, ci:)
Een standaard manier om commits te benoemen. feat = nieuwe functie, fix = fout opgelost, docs = documentatie, chore = onderhoud, ci = automatisering.
