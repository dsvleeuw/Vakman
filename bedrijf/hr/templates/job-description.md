## 2. Over Klusbaas

Klusbaas genereert demo marketing websites voor Nederlandse vakmensen (timmerman, hovenier, schilder, loodgieter, elektricien, stukadoor). Een vakman kiest vak + stijl, vult gegevens in, en krijgt een complete demo site met diensten, prijscalculator, portfolio, reviews, booking en contact flows.

**Onze missie**: Vakmensen zichtbaar maken met een professionele website die écht klanten binnenhaalt — zonder technische hassle, zonder abonnement, met eigenaarschap van code en domein.

**Stack**: React 19, TypeScript, Vite, Tailwind CSS v4, Netlify Functions, Netlify Blobs, Resend, Firebase Auth (optioneel), Bun.

**Fase**: Opbouw (0-2 jaar), 200+ betaalde klanten doel jaar 1, schaalbaar naar 500+.
